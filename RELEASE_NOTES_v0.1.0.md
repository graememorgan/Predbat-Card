## Predbat Card v0.1.0 – first release

A new Lovelace card that shows what Predbat is doing and what it plans next, with no other cards needed.

### Features
- Status header with Predbat status, mode, last update and version
- Overview tiles: battery SoC, current action and rates, cost today, savings yesterday, next charge and next export
- Battery forecast chart: best plan vs baseline, import rate, reserve, charge/export windows, hover details
- Colour-coded plan timeline and an upcoming-actions list
- Expandable full plan table
- Visual editor with all Predbat entities prefilled and a live entity check
- `prefix` option for non-default or multiple Predbat instances
- English, Polish and Spanish translations; light and dark themes

### Install
HACS → Custom repositories → `https://github.com/mimikm/Predbat-Card` (Dashboard), then add `type: custom:predbat-card`.

Feedback and translations welcome in Issues.
